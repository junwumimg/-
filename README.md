小记：在学习过程中，注意各个变量的数据类型，尤其是维度问题以及标量向量

学习过程：先看结构，再看代码，很多算法其实代码形式没什么变化，只是添加和变化了一些步骤或者数据类型，看懂代码然后用这些代码改成自己需要的东西或项目即可
比如迷宫类问题，可以自加上队列变成贪吃蛇，算法主题没有改变但是要加上些适配内容需要的改进
